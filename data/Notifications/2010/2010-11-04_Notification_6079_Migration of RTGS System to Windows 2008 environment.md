ToAllRTGSMembers

Dear Sir,

Migration of RTGSSystem toWindows 2o08 environment

Please refer to our circular DIT (CO) Circular No. 5/09.63.08/2009-10 dated November

23, 2009 on upgradation of RTGS System to Windows 2008 environment wherein the

specification for hardware and software required for the upgradation was given and

members were advised to be in readiness with the new system for undertaking the

migration.

2.

The Participant Interface (Pl) software on Windows 2oo8 environment has since

been made ready and the migration schedule for members has been drawn up.

Members will have to complete the migration process as per the schedule enclosed.

The migration process is expected to be completed by December 31, 2010.

3.

You are requested to ensure readiness with the required infrastructure for

migration on the scheduled date and confirm the same to us by email

4.

Please acknowledge receipt of this circular by return email.
