# Up-gradation of CFMS System to Windows 2008

<!-- PAGE 1 -->

RBI/2010-11/273 DPSS (CO) RTGS No. **1605** /04.08.002/2010-11 November 12, 2010 To All CFMS Members Dear Sir, <u>Up-gradation of CFMS System to Windows 2008</u> As you are aware that CFMS system is presently running on Windows 2000 advanced server with IBM Websphere MQ series 5.3.

2. It has been decided to upgrade CFMS system to the latest available software versions i.e. Microsoft Windows 2008 Enterprise Edition and IBM Websphere MQ series 7.0.
3. In order to facilitate the upgradation, we enclose Hardware and Software specifications for Server and Client machines. It may be noted that hardware specifications mentioned are the minimum requirements. However, you may decide the size of the hardware based on your specific needs.
4. The necessary application software is provided herewith.
5. We advise you to migrate from the existing system to new version on or before December 31, 2010.
5. Please acknowledge the receipt. Yours faithfully,
# Withdrawn w.e.f November 16, 2021

(G. Srinivas) General Manager Encl: 2
