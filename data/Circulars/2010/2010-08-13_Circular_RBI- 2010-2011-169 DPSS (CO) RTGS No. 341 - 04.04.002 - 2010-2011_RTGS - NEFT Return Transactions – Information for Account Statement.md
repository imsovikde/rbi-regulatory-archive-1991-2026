# RTGS / NEFT Return Transactions – Information for Account Statement

<!-- PAGE 1 -->

RBI / 2010-11 / 169 DPSS (CO) RTGS No. 341 / 04.04.002 / 2010-2011 August 13, 2010 Chairman and Managing Director / Chief Executive Officer of all banks participating in RTGS and NEFT Madam / Dear Sir,

|in RTGS Return messages uniformly. Return transactions.|RTGS / NEFT Return Transactions – Information for Account Statement Please refer to our circular RBI / 2008-09 / 499 (DPSS CO RTGS No. 2246 / 04.04.002 / 2008-2009) dated June 16, 2009. The banks were advised to provide necessary information However, it has been brought to our notice that the customers are not provided with the necessary information on 'Return' transaction in their account statement. In the absence of required information in the account statement customers face reconciliation issues. Accordingly it has been decided that all RTGS and NEFT member banks should provide the following description in the account statement of customers for RTGS and NEFT|
|---|---|
|RTGS / NEFT|Description to be provided|
|RTGS transactions|Return RTGS-RETURN-<Original UTR Number>-<Intended Beneficiary Customer>-<Reason for Return>|
|NEFT transactions|Return NEFT-RETURN-<Original UTR Number>-<Intended Guidelines with effect from April 7, 2026 Beneficiary Customer>-<Reason for Return>|

2.
3.
4. All RTGS and NEFT participants are advised to implement the instructions latest by October 1, 2010.
