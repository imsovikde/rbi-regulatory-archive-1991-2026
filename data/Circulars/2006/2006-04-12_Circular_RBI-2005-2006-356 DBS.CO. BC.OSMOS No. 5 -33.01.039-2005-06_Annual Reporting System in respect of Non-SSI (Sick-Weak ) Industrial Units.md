# Annual Reporting System in respect of Non-SSI (Sick/Weak ) Industrial Units

<!-- PAGE 1 -->

RBI/2005-06/356 DBS.CO. BC.OSMOS No. 5 /33.01.039/2005-06 April 12, 2006

The Chairman, Chief Executive Officer All Scheduled Commercial Banks (excluding RRBs)

Dear Sir/Madam,

<u>Annual Reporting System in respect of Non-SSI (Sick/Weak ) Industrial Units</u>

Please refer to letter IECD.No. 7/06.33.01/98-99 dated August 19,1998 on the captioned subject read with circular IECD No.14/01.01.43/2003-04 dated June 30,

2004.
2. It has been decided to revise the part of the format of the return which pertains to Non-SSI (Sick/Weak) units. The revised format of the return is enclosed. Banks will be required to report the annual return in the revised format from the period ending March 31, 2006. A new software package have been developed for the data input and the banks are required to send the data on a floppy as also through e-mail to: <u>mparameswaran@rbi.org.in</u> The data on the basis of which the required report in the revised format would be generated by the Reserve Bank of India directly. The data is required to be submitted latest within a month from the end of the period to which it relates.
3. It has also been decided that, as a one time measure the banks are required to furnish data in the revised format for the period ending March 31, 2004 and March 31,
2005. The data is to be submitted through e-mail to: <u>mparameswaran@rbi.org.in</u> by May 31, 2006.
# Withdrawn

4. Two executable files (.exe) containing the modified software and a word file containing the detailed guidelines regarding installation and the data entry of the revised software have been ported on our website which can be accessed by clicking on the following link: <u>[http://www.rbi.org.in/osmos/](http://www.rbi.org.in/osmos/)</u> Please download and unzip the files and follow the instructions contain in the detailed guidelines to load the package.
Yours faithfully,

(G.Gopalakrishna) Chief General Manager-in-Charge Encl: 1
