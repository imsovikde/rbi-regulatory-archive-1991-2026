# Security Policy

## Supported Versions

| Version | Supported          |
| :---    | :---               |
| 1.0.x   | Yes                |
| < 1.0   | No                 |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, do not report it through public issue trackers.

Please send an email directly to Souvik Dey at `imsovikde@gmail.com` with:
1. A clear description of the vulnerability.
2. Steps to reproduce or proof-of-concept payload.
3. Potential impact on edge workers or upstream databases.

You will receive an acknowledgment within 48 hours. Valid reports will receive coordinated patches and attribution upon disclosure.
